# Teste prático MS-102

Aplicação de estudo com 556 questões, disponível em português brasileiro e inglês, com seleção por tópico e sorteio de até 60 questões por tentativa.

## Como baixar e utilizar

1. Clique no arquivo MS-102-Teste-Pratico-Offline.zip listado neste repositório.
2. Clique em Download raw file para baixar.
3. Descompacte todo o conteúdo do ZIP.
4. Abra a pasta MS-102-Teste-Pratico.
5. Abra o arquivo index.html no seu navegador.
6. Escolha o idioma e o tópico desejado e inicie o teste.

Não é necessário instalar Node.js ou iniciar um servidor. O teste funciona offline.

## Funcionalidades

- Português brasileiro e inglês.
- Questões aleatórias, com filtro por tópico.
- 321 questões com correção automática.
- 235 questões com conferência visual assistida.
- Salvamento de progresso e histórico no navegador.
- Importação e exportação da base em CSV.

## Observações

- Descompacte tudo antes de abrir o index.html.
- Mantenha os arquivos e a pasta assets juntos.
- Para retomar uma tentativa, use o mesmo navegador e mantenha a pasta no mesmo local.
- Limpar os dados do navegador pode apagar o progresso.
- As traduções são automáticas e as imagens preservam o idioma original.
- Nem todos os gabaritos da fonte foram validados individualmente.
- Material independente de estudo, sem vínculo oficial com a Microsoft. O resultado não equivale à pontuação do exame.
